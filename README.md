# WSM – Windows Scripts Manager

Installer und Updates für WSM.

## Installieren
1. Unter **Releases** die neueste `WSM-Setup.exe` herunterladen
   (direkt: https://github.com/SweedyTry/WSM/releases/latest/download/WSM-Setup.exe).
2. Starten → „Installieren“. Es werden keine Administratorrechte benötigt.
3. Windows zeigt eventuell „Unbekannter Herausgeber“: „Weitere Informationen“ → „Trotzdem ausführen“.

WSM aktualisiert sich danach automatisch. Deinstallieren: Windows-Einstellungen → Apps → WSM.

Zu jedem Release gehört eine `WSM-Setup.exe.sha256` mit der Prüfsumme der Datei.
